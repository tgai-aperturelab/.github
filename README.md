# 光圈科技实验室 · GitHub 组织主页

本仓库用于展示 [tgai-aperturelab](https://github.com/tgai-aperturelab) 的公开组织首页。

- `profile/README.md`：组织概览页的介绍、项目与参与入口。
- `profile/assets/header-light.svg`：浅色主题横幅。
- `profile/assets/header-dark.svg`：深色主题横幅。
- `THIRD_PARTY_NOTICES.md`：沿用图形的来源说明。

GitHub 从公开 `.github` 仓库默认分支的 `profile/README.md` 显示组织介绍。更新文字或图片后，检查组织概览页的浅色、深色显示与链接。

项目介绍以对应仓库和官网为准。成员作品统一链接到官网成员墙；不在此重复维护名单、联系方式或临时入群二维码。

参考：[GitHub 组织主页文档](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)。
