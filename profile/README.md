# 光圈科技实验室

**把好奇变成行动，把想法做成作品。**

我们是一个围绕项目开展实践的学生社团，关注软件与人工智能、机器人与电子制作、网络与系统。这里欢迎不同专业、不同基础的同学，一起开发、测试、记录，把感兴趣的事情一步步做出来。

[访问官网](https://aperturelab.space/) · [成员作品](https://aperturelab.space/members/) · [参与协作](https://aperturelab.space/collaborate/) · [联系实验室](https://aperturelab.space/contact/)

## 我们在做什么

### [Shittim-Chest · 什亭之匣](https://github.com/tgai-aperturelab/Shittim-Chest)

面向 QQ 的事务处理与多人协作 Agent，由社团共同开发。探索连续会话、工具执行、文件处理与交付，让 AI 参与实际协作。目前处于开发迭代阶段。

[查看项目](https://github.com/tgai-aperturelab/Shittim-Chest) · [贡献指南](https://github.com/tgai-aperturelab/Shittim-Chest/blob/main/CONTRIBUTING.md)

### [ApertureLab · 社团官网](https://github.com/tgai-aperturelab/aperturelab-site)

社团的公开内容入口，汇集项目、成员作品、开发文档和协作资料。成员通过个人展示网页介绍兴趣与创意，也可以从页面、资料和文档改进开始参与维护。

[访问网站](https://aperturelab.space/) · [浏览源码](https://github.com/tgai-aperturelab/aperturelab-site) · [开发文档](https://aperturelab.space/docs/)

## 一起探索的方向

- **软件与人工智能** — 软件开发、AI 应用与工具实践。
- **机器人与电子制作** — 机器人、嵌入式与电子原型。
- **网络与系统** — 网络连接、系统维护与服务运行。

方向可以交叉，参与也不只限于写代码。设计、文档、测试、宣传和活动组织，同样是协作的一部分。

## 从这里开始

- **想认识大家**：到[成员墙](https://aperturelab.space/members/)看看大家的兴趣与作品。
- **想做第一份作品**：按照[个人展示网页指南](https://aperturelab.space/member-guide/)制作自己的页面，零基础也可以参加。
- **想参与项目**：阅读感兴趣项目的说明和贡献指南，从一个具体问题或改进开始。
- **有想法，或想加入**：查看[参与方式](https://aperturelab.space/collaborate/)，或[联系实验室](https://aperturelab.space/contact/)交流。
